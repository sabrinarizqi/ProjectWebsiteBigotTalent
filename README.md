# Bi-Got Talent — Aplikasi Web Pengelolaan Kompetisi & Unjuk Bakat Murid

**Bi-Got Talent** adalah aplikasi web pengelolaan kompetisi dan unjuk bakat murid yang dikembangkan sebagai proyek Ulangan Harian (UH 2) mata pelajaran **Pemrograman Web 2** di **SMK Bina Informatika** di bawah bimbingan **Ms Nia Adiyanti**. Aplikasi ini membantu menyederhanakan proses pendaftaran peserta, manajemen kategori lomba, dan penilaian secara terpusat.

## Key Features
* Registrasi Peserta & Manajemen Kategori Bakat
* Penjadwalan Tampil & Manajemen Data Peserta
* Sistem Penilaian / Evaluasi Juri
* Role-Based Access Control (Admin, Juri, Peserta/Murid)
* Rekapitulasi Hasil & Laporan Kompetisi

## Technology Stack
HTML, CSS, Bootstrap, JavaScript, PHP, Laravel, MySQL, dan GitHub.

## Project Goal
Membangun solusi digital berbasis web yang terstruktur, efisien, dan mudah digunakan untuk mendigitalisasi pendataan dan kompetisi bakat murid di sekolah
